# Experiment results

The current **simple, original-scale QQ plots** are in [simple/](simple/).
They use 2,000 independent chains per sampler/target, 30,000 total iterations,
10,000 burn-in iterations, and process parallelism for every sampler.

The files directly in this directory are the earlier 128-chain experiment,
with two-sided tail indicators and overlaid square-root-n errors. They are
retained as historical results; the current code and instructions describe
[simple/](simple/).
